## ЭТАП 1. ФУНДАМЕНТ

- **V-01. Дизайн-токены.** Все цвета/радиусы/тени/тайминги в `:root`. Палитра по ролям: убийца — кровавый, выживший — латунь, место — болотный. Сейчас цвета размазаны по 6400 строкам — начать с инвентаризации `var(--*)`, добить остатки.
- **V-02. Типографическая шкала.** Oswald для заголовков, Inter для текста, Special Elite для «бумажных» вставок. Задать 7 ступеней размера + межстрочные. Проверить, что лор читается на телефоне без зума.

## ЭТАП 2. ПЕРВЫЙ ЭКРАН И ШАПКИ ВКЛАДОК

- **V-04. Hero v2.** Слои с параллаксом (фон → фигура → туман → текст), кинетический заголовок, штамп «ДЕЛО №001» с датой, «залипающий» номер дела в углу. Уже есть глитч и кольцо — довести до кино.
- **V-05. `page-head` на каждую вкладку.** Сейчас одна шапка на всех. Сделать разными: убийцы — кровь и насечки, выжившие — латунная бирка, карты — схема-план с координатами, предметы — склад/инвентарные номера, механики — чертёж, лор — картотека, патчи — телетайп.
- **V-06. Переход между вкладками.** Не мгновенная подмена, а короткий «перелист» дела (200–300 мс), с уважением к `prefers-reduced-motion`.

## ЭТАП 3. КАРТОЧКИ

- **V-07. Карточки персонажей v2.** Рамки по роли, «голографическая» фольга на hover, номер дела в углу, силуэт-подложка, скан-линия. 3D-наклон уже есть — добавить глубину слоёв (арт отдельно от рамки).

## ЭТАП 4. ЧИТАЛКА ЛОРА (самое важное)

- **V-10. Бумага и чернила.** Фон-лист с текстурой, поля, буквица в первой главе, «чернильные» подчёркивания.
- **V-11. Штампы.** `ЗАСЕКРЕЧЕНО`, `ПРОЧИТАНО`, `СВИДЕТЕЛЬСТВО` — как реальные печати, с поворотом и выцветанием.
- **V-12. Оглавление и пейджер.** Прогресс-кольцо, липкое оглавление с активной главой, плавный скролл между главами, «следующая глава» внизу.

## ЭТАП 5. МОДАЛКИ И НАВИГАЦИЯ

- **V-16. Модалки.** Блюр подложки, пружинное появление, читаемая типографика в досье персонажа, липкая шапка с именем при скролле.
- **V-17. Мобильная навигация.** Нижний таб-бар с иконками вместо бургера, safe-area (`env(safe-area-inset-*)`), свайп между вкладками, крупные тап-зоны ≥44px.
- **V-18. Шапка при скролле.** Уменьшение, стеклянность, скрытие при скролле вниз, появление при скролле вверх.

## ЭТАП 6. ВЕС И ДОСТУПНОСТЬ

- **V-19. Ассеты.** 42 МБ — это много. Конвертировать обложки в WebP (качество 82), `assets/maps/source/` не трогать, но сгенерировать из них превью 800px. Имена существующих файлов **сохранить** — на них ссылаются `js/*` (зона Chat 3).
- **V-20. `srcset`/`sizes`.** Для карточек карт — 2 размера. Атрибуты `loading="lazy"`/`decoding="async"` ставит Chat 3 в своих шаблонах, ты только готовишь файлы.
- **V-21. Доступность.** `prefers-reduced-motion` (глушить всё: глитч, наклон, параллакс, автопрокрутку), контраст ≥4.5:1 для текста, видимый `:focus-visible`, `aria-hidden` на декоративных слоях.
- **V-22. Дневной режим «рассекреченный архив».** Светлая тема как отдельная эстетика (бумага, синие чернила) по `prefers-color-scheme`. Дорого выглядит, дёшево делается на токенах из V-01.
- **V-23. Мета-теги и OG.** `og:image` (сгенерировать 1200×630), `og:title/description`, `theme-color`. Сейчас при шаринге ссылки нет превью — это твоя зона, строки идут в `SHARED-HEAD:B`.

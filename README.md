# FORSAKEN — fan site

Неофициальный сайт-архив по Roblox-проекту **Forsaken**: убийцы, выжившие, карты, предметы, механики, патчи и лор.

## Постоянная ссылка

Сайт публикуется через GitHub Pages:

**https://tolstiyhuy.github.io/forsaken-site/**

## Что внутри

- 8 вкладок: главная, убийцы, выжившие, карты, предметы, механики, лор, патчи
- досье персонажей с сильными и слабыми сторонами и советами
- таблица сравнения убийц с сортировкой
- досье карт с реальными скриншотами локаций, номером дела из лора и фильтрами (с делом / тип локации)
- **архив лора из 14 записей** (LR-000…LR-013): Хронос, Место, 10 персонажей, хронология, правила раунда, словарь
- читалка лора с содержанием, постраничным чтением глав, прогрессом, разделами и последовательным открытием досье
- **граф связей между делами**, блок «См. также», кликабельные ссылки `LR-###` прямо в тексте
- **прогресс восстановления архива** («X / 14») и кнопка «читать по порядку»
- **командная палитра на Ctrl/Cmd+K** — поиск по персонажам, картам, вещдокам и делам
- **поиск внутри досье** с подсветкой совпадений
- **вещдоки ВД-01…ВД-10** на вкладке «Предметы» со связкой с делами
- **хэш-роутинг**: `#/killer/chronos`, `#/map/crossroads`, `#/lore/LR-005` — перезагрузка не сбрасывает место
- журнал из 24 сборок проекта
- адаптивная вёрстка, тёмная и светлая («рассекреченный архив») темы, учёт `prefers-reduced-motion`

## Лор

Весь архив лежит в `lore/`:

- `lore/CANON.md` — библия мира: законы места, хронология по «ночам», матрица связей 11×11, 5 зафиксированных расхождений между свидетельствами
- `lore/lr-*.md` — досье; главы размечены маркерами `<!--ch id|KICKER|Заголовок-->`
- `lore/manifest.json` — единый реестр записей, из него сайт строит и карточки архива, и читалку

Каждое досье помечено уровнем достоверности: `КАНОН`, `СВИДЕТЕЛЬСТВО` или `СЛУХ` — часть текстов заведомо пристрастна, и расхождения между версиями одного события входят в канон намеренно.

## Планирование

Работа была разбита на три параллельных потока, чтобы агенты не мешали друг другу:

- `docs/PLAN.md` — договор: карта владения файлами, маркеры в `index.html`, формат лора, схема `lore/manifest.json`
- `docs/task-1-lore.md` — лор и архив (только `lore/**`)
- `docs/task-2-visual.md` — оформление, ассеты, разметка (только `css/`, `assets/`, блоки `:B`)
- `docs/task-3-features.md` — логика и фичи (только `js/`, блоки `:C`)

## Структура

```text
index.html            разметка всех вкладок
css/style.css         базовое оформление и адаптив
css/v2.css            визуальный слой v2: hero, шапки вкладок, читалка, карточки, темы
css/features.css      стили интерактивных блоков (fx-*)
js/data.js            персонажи, карты, вещдоки, devlog
js/details.js         расширенные досье
js/app.js             рендер, фильтры, модалки, роутинг, загрузчик манифеста
js/features.js        палитра, поиск, граф, прогресс архива, вещдоки
lore/CANON.md         библия мира (внутренний документ)
lore/lr-*.md          досье архива
lore/manifest.json    реестр всех 14 записей (контракт лор ↔ код)
docs/                 план работ на три потока
assets/               арт персонажей, обложки карт, OG-превью
assets/maps/source/   исходные скриншоты карт (сайтом не используются)
```

## Локальный запуск

Из-за `fetch()` для лора сайт нужно открывать через локальный сервер:

```bash
python -m http.server 5173 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:5173/`.

## Публикация

Сайт статический, без сборки. GitHub Pages раздаёт ветку `main` из корня репозитория. Файл `.nojekyll` отключает обработку через Jekyll.

После правок `css/*.css` или `js/*.js` поднимай номер `?v=` у подключённых файлов в `index.html` — иначе браузер может показать старую закэшированную версию. Текущая версия — `?v=10`.

Новое досье в архив добавляется без правок кода: положи `.md` в `lore/`, добавь запись в `lore/manifest.json` — и оно появится в архиве, графе связей, палитре и поиске.
